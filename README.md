# G.D.B. — Guitar Digitization Builder 

Одностраничное веб-приложение: гриф гитары на 24 лада с синтезом звука через Web Audio API.

## Что умеет

- **Гриф 0–24 лад.** Клик по точке — воспроизведение ноты.
- **Визуальные настройки:**
  - подписи нот на грифе вкл/выкл;
  - переключение диезов и бемолей;
  - подсветка выбранной ноты и цвета доступных ладов.
- **Настройка строя.** Несколько пресетов (стандарт, Drop D, Open G и т.д.) + кнопка сброса. Приложение даёт возможность пользователю создавать кастомный строй.
- **Конструктор аккордов.** Можно выбрать какие конкретно ноты будут состоять в аккорде. Приложение визуально подсвечивает на гриффе все возможные позиции построения любого аккорда, подстраиваясь при этом под любой строй
- **Конструктор гамм.** Задаёшь тонику и позиции ступеней от 1 до 12 и приложение расставляет их по грифу, подсвечивая цветами.
